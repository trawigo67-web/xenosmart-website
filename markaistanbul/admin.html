Bu adım sadece bir kez yapılır. GitHub anahtarı (token) şifrenizle kilitlenip saklanır. Sonra herkes sadece şifreyle girer.

Anahtar nasıl alınır: GitHub → Fine-grained token → Repository access: Only select repositories → xenosmart-website → Permissions: Contents: Read and write ve Actions: Read and write → Generate token.

📲 Telefona uygulama olarak ekleyin: iPhone'da Paylaş → „Ana Ekrana Ekle“, Android'de menü ⋮ → „Uygulamayı yükle“.
